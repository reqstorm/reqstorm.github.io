# reqstorm.github.io

The documentation site for [reqstorm](https://github.com/melihcolpan/reqstorm), published at **https://reqstorm.github.io**.

The pages are written in [`docs/`](https://github.com/melihcolpan/reqstorm/tree/master/docs) of the reqstorm repository, next to the code. The workflow here builds them with MkDocs Material and deploys the site every day and on demand (Actions, "Build and deploy the site", Run workflow).
